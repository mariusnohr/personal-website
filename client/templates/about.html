Hello.

My name is Marius Nohr. I was born in the summer of '87, in Oslo, Norway.

In my professional life I work as a creative developer at TRY Apt. In other words, I like code as much as I like design. As a creative developer you really get to do a mix of both. It's in the intersection between code and design I do my best work.

I also like to play with animation, interactivity, generative/procedural art, ui/ux, math and physics. This website functions as a personal archive of all the things I experiment with in my spare time.

The tech behind this site

The backend is pretty much a static site using Koa running on Node. The frontend is a mix of my own little framework and masonry/isotope. It's also using some visuals rendered with my go to WebGL-framework Three.js. Each deploy is built using Parcel as the package manager. That's pretty much it.
